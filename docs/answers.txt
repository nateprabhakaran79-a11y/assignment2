8. Inheritance: a class acquires the attributes and methods of another class, so it can reuse and extend that code.
Polymorphism: objects of different classes can be used through the same interface, and each responds in its own way.
Encapsulation: data and the methods that work on it are bundled inside a class, and internal details are hidden from outside code.

9. In the Integration Manager workflow, one integration manager merges every developer's changes and resolves all conflicts. In the Dictator and Lieutenants workflow,
 integration is split up: lieutenants merge changes for their group of developers, and the dictator merges only the lieutenants' work into the blessed repository.

10. In the Centralized workflow, all 100 developers push to one repository, which leads to constant conflicts. With Dictator and Lieutenants,
 lieutenants resolve conflicts within their groups first, so the dictator only integrates a few repositories. This spreads out the work and keeps the main repository stable.
